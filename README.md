# Mini Site — Dr. Douglas Martins

Implementação inicial responsiva em Next.js + React + TypeScript, baseada na imagem de referência enviada.

## Rodar localmente

1. Instale Node.js 18.17 ou superior.
2. No terminal, entre nesta pasta e execute `npm install`.
3. Execute `npm run dev`.
4. Abra `http://localhost:3000`.

## Personalização necessária antes de publicar

- Substituir os textos provisórios e o texto Lorem ipsum original por conteúdo aprovado.
- Atualizar o e-mail `contato@douglasmartins.com.br` para o endereço real.
- Confirmar os números de experiência/casos antes de publicar.
- Substituir os recortes provisórios pelas fotografias originais de maior qualidade, se disponíveis.
- Confirmar links de redes sociais, agendamento e páginas externas.

As imagens incluídas são recortes extraídos da imagem de referência; para qualidade ideal, use os arquivos fotográficos originais.
